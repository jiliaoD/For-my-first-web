# 加藤惠主题站-视觉与交互方案

## 1. 文档目的
本文件用于承接前置研究结果，明确本项目在视觉方向、页面节奏、动效方案、音频策略与第三方库选型上的建议，供后续设计与实现阶段直接复用。

本文件只定义方向与策略，不包含实现代码。

## 2. 总体设计判断

### 2.1 设计目标
这个站点不适合做成高饱和、强冲击、强对比、重粒子特效的“角色海报站”。

更适合的方向是：
- 轻
- 静
- 柔
- 有留白
- 有后劲
- 通过细节层次而不是爆炸式装饰建立高级感

### 2.2 设计核心
要表达的不是“一个信息量很大的动画页面”，而是“一个围绕加藤惠气质建立的、安静但成立的单页体验”。

因此视觉上应把重点放在：
- 情绪氛围
- 排版节奏
- 空气感
- 春日与日常意象
- 从淡到明的主角化过程

## 3. 视觉方向建议

### 3.1 推荐主方向：春日轻叙事
关键词：
- 春日
- 樱花
- 坡道
- 日光
- 轻风
- 日常
- 白色与浅粉
- 清透灰蓝

视觉印象应接近：
- 清晨或午后柔光
- 纸张与玻璃叠加的轻薄层
- 带有日系杂志感的编排
- 比“宅向海报”更接近“角色印象集”

### 3.2 备选方向：低存在感的高级留白
若后续不想过度使用“樱花粉”，可以转为更克制的方向：
- 大面积留白
- 低饱和灰白与雾蓝
- 少量淡粉只用于强调
- 文字、细线、微透明层建立精致感

这个方向更适合在缺少授权角色图时使用，因为它更依赖排版和层次。

### 3.3 不推荐方向
- 大面积高饱和二次元粉紫渐变
- 明显“手游活动页”式堆料
- 重霓虹、重科技 HUD、赛博风
- 大量闪烁粒子、夸张 3D 透视和过强镜头运动
- 过度模仿官方视觉图排版

原因：
- 角色气质不匹配
- 无官方图时会显得空
- 容易把页面重心从“人物印象”推向“装饰炫技”

## 4. 配色建议

### 4.1 主配色
- 主背景：米白 / 暖白
- 一级强调：浅樱粉
- 二级强调：灰蓝 / 雾蓝
- 中性层：浅灰、银灰、淡米灰
- 深色文字：偏冷深灰，不建议纯黑

### 4.2 推荐色板
- `#F7F4F1` 纸面暖白
- `#F3E3E8` 浅樱粉
- `#D8E3EA` 雾灰蓝
- `#C9CCD6` 轻银灰
- `#6E7381` 冷灰文字
- `#2F3440` 深层标题

### 4.3 使用原则
- 粉色不是主压迫色，而是点缀色。
- 背景颜色尽量轻，避免把页面做成大面积粉墙。
- 用灰蓝平衡甜感，避免过分少女海报化。
- 强调按钮或标签也应克制，少用高纯度色块。

## 5. 字体与排版建议

### 5.1 中文字体建议
- 标题：`Noto Serif SC` 或同类可合法使用的宋体/衬线字体
- 正文：`Noto Sans SC` 或同类清晰无衬线字体

选型理由：
- `Noto Serif SC` 适合承接“轻文学感、作品感、印象集”的气质
- `Noto Sans SC` 适合正文说明、卡片、标签等信息层
- Noto 系列适合中日文混排与 Web 使用

### 5.2 排版原则
- 标题不宜过粗
- 行距略松
- 模块之间拉开距离
- 允许更大的留白和更少的边框
- 一屏只保留一个明确视觉中心

### 5.3 文本层级建议
- 主标题：偏短，情绪性
- 副标题：解释主题，不做长句堆砌
- 模块标题：2-5 字为佳
- 正文：短段落优先，避免百科式大块文字
- 引语：谨慎使用，避免大量直接引用原作台词

## 6. 页面节奏建议

### 6.1 推荐节奏
1. 第一屏先给情绪
2. 第二屏给角色认知
3. 第三屏解释“为什么是她”
4. 第四屏补作品中的位置
5. 第五屏做视觉停留
6. 结尾交代站点边界与说明

### 6.2 节奏控制原则
- 前 2 屏必须轻，不要一开始信息爆量
- 中段提升内容密度，但仍保持安静
- 后段留一个观感停留区，让用户不必一直读字
- 页尾回到克制说明，不做大开大合的结束

## 7. 动效方案

### 7.1 动效总原则
- 动效服务于“轻”和“后劲”，不是做存在感竞赛
- 用位移、透明度、模糊、遮罩和层次差建立节奏
- 少用弹跳、抖动、夸张缩放
- 所有关键动画都要有 `prefers-reduced-motion` 降级方案

### 7.2 首屏入场建议
推荐效果：
- 背景先缓慢浮现
- 标题轻微上移并淡入
- 装饰层做极弱的视差或漂移
- 首屏不要自动播放音频

不推荐：
- 大范围旋转
- 多层爆炸散开
- 快速缩放推进
- 粒子满屏飞

### 7.3 滚动触发建议
适合做的效果：
- 文本块轻微上浮淡入
- 图片/面板由轻模糊过渡到清晰
- 分割线或小标签延迟出现
- 背景层做极小幅度视差

建议每个模块只保留 1 个主要动效重点，避免同时叠加三四种效果。

### 7.4 悬停反馈建议
适合：
- 透明度微调
- 阴影轻微抬升
- 细线扩展
- 图卡轻度放大 1% 到 2%

不适合：
- 强烈翻转
- 卡片大幅旋转
- 过重磁吸效果

### 7.5 内容切换建议
若后续加入标签切换、轮播或时间线：
- 使用淡入淡出 + 小距离平移
- 切换时长控制在 0.3s 到 0.6s
- 不建议做横向大幅推屏

### 7.6 推荐动效节点清单
- Hero 标题入场
- 首屏副标题延迟出现
- 关键词卡片滚动出现
- 叙事模块遮罩淡入
- 视觉陈列区图片轻视差
- 按钮/链接 hover 微反馈
- 页尾说明区弱化收束

## 8. 图片呈现策略

### 8.1 在无角色授权图前提下的呈现方法
推荐使用：
- 抽象渐变背景
- 樱花、街道、书页、窗光、布料等氛围摄影
- 细线框、半透明面板、文字短句组成的陈列区
- 模糊景深与局部裁切，避免页面显得空

### 8.2 如果后续拿到合法图片
也不建议直接大面积满屏铺图。

更推荐：
- 单图焦点
- 留白裁切
- 竖向卡片画廊
- 小型轮播
- 图片与文本混排

原因：
- 更符合角色气质
- 更容易控制页面高级感
- 降低素材质量参差带来的视觉问题

## 9. 音频策略

### 9.1 当前推荐
默认不开启站内 BGM。

理由：
- 本项目核心体验靠视觉与文案也能成立
- 原作音乐版权边界不清晰，风险高
- 自动播放会带来浏览器限制与用户体验问题

### 9.2 若后续确需加音频
只建议使用：
- 授权明确的免版税环境音
- 极轻的钢琴或 Lo-fi 氛围音
- 自制 UI 点击音或切换音

必须满足：
- 手动开启
- 默认静音
- 可随时关闭
- 移动端可正常降级

### 9.3 不推荐音频方案
- 任何原作相关乐曲
- Cover、翻弹、扒带、二创混音
- 自动播放
- 页面加载即出声的交互

## 10. 第三方库选型建议

### 10.1 总原则
这个项目不需要堆很多库。建议优先选：
- 一个主动画库
- 一个轻量轮播库
- 一个可选音频库

滚动平滑库和重型特效库不应默认加入。

### 10.2 主动画库：Motion for React
推荐级别：高

适用场景：
- 首屏入场
- 文本和卡片淡入
- 滚动触发
- 悬停反馈
- 页面切换与布局动画

选型理由：
- 文档完整，适合 React
- 支持 `motion` 组件、手势、滚动、布局动画
- 更适合本项目这种中轻量、强调节奏和精致度的页面

结论：
- **默认首选**

### 10.3 补充动画库：GSAP
推荐级别：中

适用场景：
- 需要更精细的时间线编排
- 复杂视差和滚动联动
- 需要更底层控制时

选型理由：
- 成熟、强大、框架无关
- 适合复杂动画时间线

注意：
- 对当前项目来说，若只做常规单页动效，GSAP 不应替代 Motion 作为默认方案
- 只有在出现 Motion 难以优雅处理的高级滚动编排时，再引入更合适

结论：
- **作为增强备选，不作为默认首选**

### 10.4 轮播库：Embla Carousel
推荐级别：高

适用场景：
- 视觉陈列区
- 卡片轮播
- 小型画廊

选型理由：
- 轻量、无依赖、结构清晰
- 保留对样式和 DOM 的控制
- 更适合做“克制型画廊”，不容易被默认样式拖偏

结论：
- **若需要轮播，优先选 Embla**

### 10.5 音频库：Howler.js
推荐级别：中

适用场景：
- 需要一个稳定的 Web 音频控制层
- 需要音频开关、淡入淡出、音频片段控制

选型理由：
- API 简洁
- 跨浏览器表现成熟
- 适合轻量站点音频控制

结论：
- **仅在确认接入合法音频素材后再引入**

### 10.6 平滑滚动库：Lenis
推荐级别：低到中

适用场景：
- 页面后续真的要做明显滚动氛围感
- 且需要统一滚动体验与滚动联动效果

注意：
- 不是必需品
- 对当前项目而言，若只是轻量滚动淡入，不应为“平滑滚动”单独加库
- 引入前要优先评估可访问性、性能、输入设备兼容与实现复杂度

结论：
- **默认不引入；仅在设计明确依赖滚动手感时再考虑**

## 11. 推荐组合方案

### 方案 A：最稳妥
- 动画：Motion for React
- 轮播：Embla Carousel
- 音频：不接入

适用：
- 当前阶段最合理
- 风险最低
- 与“无官方图、无原曲”策略最匹配

### 方案 B：增强版
- 动画：Motion for React
- 特殊滚动段落：GSAP 局部补充
- 轮播：Embla Carousel
- 音频：Howler.js

适用：
- 后续获得合法素材
- 需要更强滚动编排
- 项目目标从“轻兴趣站”升级为“高质展示页”

### 方案 C：不推荐
- 同时引入多个动画库和多个滚动库
- 首屏大量视频、粒子、平滑滚动、背景音乐一起上

问题：
- 技术复杂度高
- 页面气质容易失控
- 与当前内容边界和素材策略不匹配

## 12. 落地建议

### 12.1 当前最适合本项目的设计结论
- 视觉：春日轻叙事 + 留白 + 低饱和粉/灰蓝
- 内容：文字与意象驱动，不依赖官方角色图
- 动效：轻入场、轻滚动、轻悬停
- 音频：默认关闭，不内置原作相关音乐
- 库：`Motion for React + Embla Carousel` 作为主推荐组合

### 12.2 实现阶段注意点
- 所有动画都要提供降级方案
- 素材来源必须可追溯
- 不因为“页面空”就临时塞版权不明图片
- 不因为“更有氛围”就默认加 BGM
